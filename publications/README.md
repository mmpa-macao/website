# publications/

每一期刊物放兩個檔案，路徑與檔名要和 `publications-data.js` 一致：

| 檔名 | 內容 |
|---|---|
| `template-cover.jpg` | 測試用 |
| `template.pdf` | 測試用 |
| `yearbook-01-cover.jpg` | 第 1 期封面（JPG，寬約 900 px，300 KB 以下） |
| `yearbook-01.pdf` | 第 1 期 PDF（建議壓縮到 20 MB 以下，手機開啟較順） |

第 2 期以後依序命名 `yearbook-02-cover.jpg`、`yearbook-02.pdf`，再到 `publications-data.js` 新增一筆。
